DocSafe – Maquettes

Phase 2 ·

Ces maquettes montrent l'apparence et le contenu prévus de chaque écran. Les documents affichés sont des exemples. Le bouton Clair / Sombre change le thème de tous les écrans. Chaque écran est dessiné pour un petit téléphone (360 × 784 points), la taille la plus répandue en entrée de gamme. Les règles de design sont décrites dans docs/07-design.md.

Icônes : Material Symbols (Google, licence Apache 2.0). Police : Roboto si elle est disponible, sinon celle du système. Les maquettes ne sont pas l'application : elles servent à valider le design avant le développement.
